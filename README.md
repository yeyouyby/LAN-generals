# ♛ LAN-generals 局域网将军棋

generals.io 玩法复刻，**同一 WiFi 下打开浏览器即玩，无需公网、无需注册**。

一人开服，同事 / 同学 / 家人用手机或电脑浏览器打开房主的地址，就能一起抢地盘、抓将军。

## ✨ 特性

- 🏠 大厅 + 房间 + 观战，2~8 人一局，手机 / 电脑浏览器都能玩
- 🤖 人不够可加电脑（AI），1 个人也能开；掉线自动托管，重进回来继续打
- 🌫️ 战争迷雾、上帝视角观战、城市 / 将军营视野加成
- ⚔️ 抓将军接管全部土地、半数出兵、投降、再来一局
- 📋 行军队列：点击自动寻路、方向键连续行军、Z 撤销 / X 清空
- 💬 房间聊天、战况计分板、将军受威胁告警、简易音效
- 📴 全离线运行：前后端零外部依赖（唯一的 `ws` 库只在开服机器上安装一次）

## 🚀 快速开始

### 1️⃣ 开服（任选一台电脑，只需一次）

需要 [Node.js 16+](https://nodejs.org/)（Win / Mac / Linux 均可）。

```bash
npm install   # 只需第一次
npm start
```

或双击运行：Windows 用 `start.bat`，Mac / Linux 用 `start.sh`。

看到下面这样就是成功了：

```
⚔️  LAN-generals 已启动！

本机游玩：  http://localhost:3000
局域网联机（把下面地址发给同一 WiFi 的朋友）：
  👉 http://192.168.1.8:3000
```

### 2️⃣ 加入（所有玩家，含手机）

- 房主自己打开 `http://localhost:3000`
- 其他人连**同一个 WiFi**，浏览器打开上面 👉 的地址
- 改个名字 → 创建 / 加入房间 → 凑齐 2 人以上（可加电脑）→ 开战！

## 🎮 玩法

| 图标 | 含义 |
| ---- | ---- |
| ♛ | 将军营：你的老家，每回合 +1 兵，被抓住就出局 |
| ◆ | 城市：30~45 守军，攻下后每回合 +1 兵 |
| ▲ | 山地：不可通行 |
| 🌾 | 每 25 回合，所有己方土地 +1 兵 |

**目标**：扩张地盘、发展兵力，抓住所有敌人的将军营，活到最后。

**拼兵规则**：进攻时双方兵力相抵，剩得多的一方占领该格。

### 操作

| 操作 | 方式 |
| ---- | ---- |
| 选中 / 行军 | 点击己方格选中，再点目标（自动寻路，可点远处） |
| 连续行军 | `WASD` / 方向键 |
| 半数出兵 | `Q` 切换模式，或按住 `Shift` 点击 |
| 撤销一步 / 清空队列 | `Z` / `X`，或点按钮 |

## ⚙️ 配置

| 环境变量 | 说明 | 默认 |
| -------- | ---- | ---- |
| `PORT` | 服务端口 | `3000` |

房间内可调：人数（2~8）、地图（小 15×15 / 中 20×20 / 大 26×26 / 自适应）、速度（慢 1s / 标准 0.5s / 快 0.25s 每回合）。

## ❓ 常见问题

**朋友打不开地址？**
- 确认连的是**同一个 WiFi**（不是流量，也不是访客网络隔离模式）
- Windows 首次运行会弹防火墙提示，点「允许访问」；或手动放行 Node.js / 3000 端口
- 公司网络可能隔离设备互访，换手机热点试试（一人开热点，其他人连，房主用热点 IP 开服）

**端口被占用？** `PORT=8080 npm start` 换个端口。

**手机上能玩吗？** 能。用触屏点击行军，建议横屏 + 标准/慢速局。

**掉线了怎么办？** 你的席位会由电脑托管，重新打开地址点「⚔️ 重回战场」即可（同一浏览器直接重连回去）。

**想复盘 / 围观？** 点房间的「观战」，上帝视角看全图。
